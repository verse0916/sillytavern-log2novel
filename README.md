# 酒馆拾页｜SillyTavern JSONL → TXT / EPUB

把 SillyTavern (酒馆) 导出的 `.jsonl` 聊天记录，清洗成干净的纯文本，
方便你把喜欢的一段角色扮演经历整理成一本"小说"来读。

现在提供适合手机和电脑使用的网页版本。日志只在浏览器本地解析，不上传服务器；网页加载完成后，清洗和导出过程不需要联网。

## 网页版

直接打开 `index.html` 即可使用：

1. 选择或拖入 SillyTavern 导出的 `.jsonl`；
2. 检查自动清洗结果，需要时直接编辑；
3. 下载 TXT，或填写书名、作者、封面和章节规则后生成 EPUB。

AI 消息默认抽取 `<content>` 标签，也可以在页面上填写其他正文标签。没有匹配到标签的 AI 消息会明确列出并默认保留原文，避免内容静默丢失。

EPUB 支持：

- `Chapter 1`、`第一章`、`第1章` 等常用章节标题；
- 将短行作为章节标题的简化模式；
- 自定义正则表达式；
- 目录、基础中文排版，以及可选 JPG / PNG 封面。

### 部署到 GitHub Pages

仓库不需要构建步骤。在 GitHub 仓库的 **Settings → Pages** 中，将来源设置为当前分支的根目录，保存后即可获得公开网址。公开的只是网页程序，访客选择的聊天记录仍只在其自己的浏览器中处理。

## 命令行版本

- 读取酒馆导出的 `.jsonl` 聊天记录
- 自动提取每条 AI 回复里 `<content>...</content>` 包裹的正文，丢掉思维链、
  状态面板等其他内容
- 保留你自己发的所有消息
- 输出一个干净的 `.txt` 文件

原有 `clean.py` 仍可使用，适合习惯命令行的用户。

只需要电脑上装了 Python 3（Mac/Linux 自带，Windows 需要自己装一下，
搜"Windows 安装 Python"就有教程，或者直接问 AI 怎么装）。

1. 下载本仓库（点击右上角绿色 Code 按钮 → Download ZIP，或者用
   `git clone` 都行）
2. 打开终端，进到解压后的文件夹，运行：

   ```bash
   python3 clean.py 你的聊天记录.jsonl
   ```

   会在同目录下生成 `你的聊天记录_cleaned.txt`。

就这两步。

## 如果你的角色卡不是用 `<content>` 包裹正文的

大部分预设最终正文都会用 `<content>` 标签包裹，如果你的不是，可以指定
标签名：

```bash
python3 clean.py 你的聊天记录.jsonl --tag 你的标签名
```

## 报错了怎么办

把终端里的报错信息复制给 AI（ChatGPT / Claude 都行），问它"这个 Python
报错是什么意思"，一般都能自己解决。也欢迎在本仓库提 Issue。

## 隐私说明

网页没有上传接口、分析脚本或外部运行时依赖。文件读取、JSONL 解析、文本编辑和 EPUB 封装都在当前浏览器标签页内完成。刷新或关闭页面后，页面不会留存聊天正文。

欢迎 PR / 提建议。
